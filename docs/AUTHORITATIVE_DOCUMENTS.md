# Authoritative documents

Use one current source for each subject:

- Architecture: `docs/SIMPLIFIED_ARCHITECTURE.md`
- Workflow ownership: `STATE_AND_OWNERSHIP_MATRIX.md`
- Deployment: `DEPLOYMENT_GUIDE.md`
- Testing: `TESTING_GUIDE.md`
- Release operation: `RELEASE_RUNBOOK.md`
- Product scope: `docs/PRODUCT_SCOPE.md`
- Active workflow contracts: `_workflows/` and `_workflows/contracts/`
- Architectural decisions: `adr/`

Completed roadmaps and historical release notes are reference material, not implementation instructions. Move them under `docs/archive/` when they no longer describe active work. Do not duplicate active workflow rules in archived documents.
